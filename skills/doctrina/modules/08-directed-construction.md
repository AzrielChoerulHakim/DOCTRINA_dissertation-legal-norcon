# Module 08 — Directed dissertation construction (new or ongoing)

Load CONSTITUTION.md first. Maintain templates/construction-ledger.md and, when useful, a local JSON ledger conforming to schemas/construction-v1.schema.json. The following are semantic gates; a recorded status is not proof.

| Stage | Required output before progression |
|---|---|
| G1 Object | One norm/judgment/concept, precise locus, jurisdiction/time, boundaries, source availability |
| G2 Problem | Text-grounded tension, missing warrant or contested interpretation; at least one plausible rival explanation |
| G3 Core idea | I-01, why the problem matters to law and what the question asks; provisional novelty direction |
| G4 Core argument | A-01 as a revisable answer, reasons, scope, strongest potential defeater; mark assistant proposals |
| G5 Architecture | SA nodes and dependencies, route, defined terms, source questions, planned intermediate conclusions |
| G6 Directed research | Search ledger, actual source locations and verification status, conflicting evidence, stop or expansion decision |
| G7 Analysis | Method-specific records, qualified intermediate results, revisions and their downstream impact |
| G8 Stress | Strongest rival interpretation, premise challenges, hard cases, objections and responses; record unresolved limits |
| G9 Final originality readiness | Integrated chapter spine, defense rehearsal, researcher sign-off; then Module 07 compares actual prior propositions |
| G10 Composition | Argument-led manuscript matching institutional format; conclusion distinguishes demonstrated contribution from open questions |

Gates are iterative, not a one-way waterfall. Draft provisional text before G9 if requested, label it draft, and never certify novelty early. For a live manuscript enter at its real stage after P1; do not replace its thesis or structure without researcher consent. For a new proposal no P1 original exists yet: keep proposals explicitly assistant-proposed until accepted. Never use a ledger as proof of acceptance.

Before each search record query target ID, uncertainty, source class, expected evidence, stopping criterion. First inspect bounded authoritative corpus; compare rival evidence and strongest nearby scholarship. Stop when question is adequately resolved or explicitly indeterminate; park unrelated leads. Review scope expansion and rationale before more search. No fixed number of papers is evidence of completeness.

For each development record parent ID and relation, actual evidence/locator, analytic move, what changes if the finding is false, objection and outcome. Distinguish the organizational path I → A → SA → D → C → S from inference direction: premises and intermediate results support conclusions, not the reverse. Background can contextualize or delimit an argument; do not disguise it as proof.

When a premise, interpretation, definition or source changes: identify all transitive dependent nodes, mark re-review required, revisit the affected gates, and record author decision. If no defensible central thesis remains, preserve failure and propose a revision rather than retrofitting evidence. Do not treat genuine dialectical development as contradiction without testing context.

Output: a concise charter, versioned argument map, research ledger, route-specific analysis, intermediate synthesis, outstanding issues and draft only at warranted depth. Read Modules 02–07 for reconstruction, audit, challenge, integration, defense and originality.
